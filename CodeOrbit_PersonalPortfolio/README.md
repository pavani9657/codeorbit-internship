# Personal Portfolio Website — CodeOrbit Tech Internship

## Features
- Responsive layout for desktop and mobile
- About Me, Skills, Projects, and Contact sections
- Mobile navigation toggle and dynamic copyright year
- Project showcase includes the Movie Search App and internship tasks

## Run
Open `index.html` in a browser. No build tools or dependencies are required.

## Before submitting
1. Replace `Your Name` with your real name.
2. Replace `your.email@example.com` with your real email.
3. Optionally add your GitHub and deployed project links.
4. Test on desktop and a narrow/mobile browser window.
