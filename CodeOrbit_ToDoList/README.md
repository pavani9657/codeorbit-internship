# To-Do List Web App — CodeOrbit Tech Internship

## Features
- Add, edit, and delete tasks
- Mark tasks complete or active
- Filter All / Active / Done tasks
- Clear completed tasks
- Saves tasks in browser `localStorage`, so they remain after refresh
- Responsive interface and basic input/error handling
- Uses only HTML, CSS, and vanilla JavaScript

## Run
Open `index.html` in a modern browser. No installation or build step is required.

## Test checklist
- Add a task and confirm it appears.
- Refresh the page and confirm it remains.
- Edit the task and save.
- Mark it complete and test the filters.
- Delete a task.
- Clear completed tasks.
- Resize the browser to check the mobile layout.

## Storage note
Tasks are stored locally in this browser under the key `codeorbit-focus-list-tasks`. They are not synced to other devices.
